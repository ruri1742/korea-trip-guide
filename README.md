# 韓国旅行しおりアプリ

韓国旅行中に、今見るべき予定だけをすぐ確認するための個人用Webアプリです。

このプロジェクトは、アプリを作りながらCodexの使い方、プロジェクト管理、Git管理、ファイル構成、ローカルでの確認方法を小さく学ぶための練習でもあります。

## 目的

- 旅行中の確認を短く、少なくする
- 現在時刻から「今見るべきステップ」を表示する
- 予定が前後しても「前のステップ」「次のステップ」を見られるようにする
- スマホで自然に使える簡素なしおりにする
- AI機能や複雑な仕組みを目的化しない

## 設計思想

- 技術優先ではなく、体験優先・目的優先で作る
- 任天堂の「枯れた技術の水平思考」のように、簡素な技術で良い体験を作る
- 旅行中のタップ数を最小にする
- 旅行中にユーザーへ状態報告を求めない
- 変に賢くしすぎない
- 既存アプリと同じくらい自然に使えることを優先する
- 表示は短く、必要な情報だけに絞る
- スマホ表示を最優先する
- 個人情報、予約番号、チケット画像そのものはサンプルに入れない

## 最初のファイル構成案

本格実装に入る前の最小構成は次の予定です。

```text
.
├── README.md
├── AGENTS.md
├── .gitignore
├── index.html
├── style.css
├── app.js
└── data.js
```

各ファイルの役割:

- `index.html`: 画面の骨組み
- `style.css`: スマホ優先の見た目
- `app.js`: 現在時刻から表示するステップを選ぶ処理
- `data.js`: 旅行予定のサンプルデータ

まだ `index.html`, `style.css`, `app.js`, `data.js` は作らず、次のステップで小さく追加します。

## ローカルでの開き方

最初はビルド環境を作らず、静的なHTML / CSS / JavaScriptだけで動かします。

基本の確認方法:

1. `index.html` を作成する
2. エクスプローラーから `index.html` を開く
3. ブラウザでスマホ幅の表示を確認する

必要になった場合だけ、簡単なローカルサーバーで確認します。

```powershell
python -m http.server 8000
```

その場合はブラウザで次を開きます。

```text
http://localhost:8000/
```

## Gitでの基本的な進め方

小さな単位で進めます。

1. 変更前に、何を変えるか短く確認する
2. ファイルを作成・編集する
3. 動作確認する
4. 変更内容を見る
5. 問題なければコミットする

よく使う確認:

```powershell
git status
git diff
```

コミットの例:

```powershell
git add README.md AGENTS.md .gitignore
git commit -m "Add project setup notes"
```

## 次の実装予定

1. `index.html`, `style.css`, `app.js`, `data.js` を作る
2. サンプル予定を3件だけ入れる
3. 現在時刻に近い予定を1件表示する
4. 「前へ」「次へ」ボタンを付ける
5. スマホ幅で見やすいか確認する
